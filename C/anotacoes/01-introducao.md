# Introdução 

## Introdução

- Os seres humanos sempre foram fascinados por **automatizarem** ou **facilitarem** as suas tarefas.
- **Algoritmos** precisam ser desenvolvidos para que possam **operar** nos computadores

### Algoritmo 
É uma **sequência finita** de passos simples, e bem definidos, capaz de realizar uma determinada tarefa.

***Exemplos*** : 
- Algoritmos de **soma/subtração/multiplição** de dois números.
- Algoritmo de fatoração de um inteiro em **números primos**.
- Algoritmo de **Euclides** para encontrar o **MDC**

> Os algorimos serão implementados utilizando a **linguagem de programação C**

## Ferramentas
- **Editor de texto** e **compilador** para a linguagem C instalado.
    - **Editor Simples** : `Bloco de Notas`, `nano` 
    - **Editor Complexo** : `Sublime`,`VisualCode`.
- O compilador utilizado será o `GCC` (GNU Compiler Collection).
